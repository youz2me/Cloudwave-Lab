# 프로젝트 작업 규칙

Cloudwave-Lab 저장소에서 코드와 문서를 변경할 때 적용하는 공통 규칙이다.

## 언어

- 사용자 대상 응답은 한국어로 작성한다.

## 저장소 성격

- 관측 가능성·AIOps 학습용 실습 킷 모음이다.
- 각 하위 폴더(예: `Bottleneck-Lab/`)는 하나의 독립적인 실습이다.
- 학습자가 관측 데이터로 병목과 이상 위치를 직접 판단해야 한다.
- README 등 실습 문서에 정답을 노출하지 않는다. 시나리오, 지표, 로그, 탐색 방향만 제공한다.

## 작업 원칙

- 요청을 충족하는 최소 범위만 변경한다.
- 추측성 기능, 설정, 추상화를 추가하지 않는다.
- 기존 코드와 문서의 스타일을 따른다.
- 변경한 모든 줄은 요청과 직접 관련되어야 한다.
- 목표, 범위, 완료 기준이 불명확하고 결과에 큰 영향을 주면 사용자에게 확인한다.

## Git

- 브랜치, 커밋, PR, 제외 파일에 관한 규칙은 [`git-convention.md`](./git-convention.md)를 따른다.
- Git 작업 전에는 해당 문서의 최신 내용을 확인한다.
